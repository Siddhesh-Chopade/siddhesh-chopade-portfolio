🛡️ Sentinel — Mobile Threat Detector

Aug 2025 – Jan 2026

Built a full-stack dashboard for detecting and monitoring malicious mobile apps based on their declared permissions. Users submit an app's name, package, and permission list; the backend computes a weighted risk score, classifies the app as benign, suspicious, or malicious, and stores the result in MySQL. Suspicious or malicious results automatically generate a contextual alert with a short explanation and a recommended action, and the dashboard surfaces the fleet-wide picture through charts, a searchable table, and a live threat ticker.

Project TypeSecurity analytics dashboard
Core FocusPermission-based risk scoring
Key FeatureContextual alerts & threat ticker
Key contributions

Built the backend with Node.js, Express, and a REST API over a normalized MySQL schema, and the frontend with HTML5, CSS3, and JavaScript. The risk engine is a transparent, weighted stand-in for a trained classifier, designed to be swapped for real model inference later.

  • Designed a weighted permission-based risk-scoring engine that normalizes results to a 0–100 scale and classifies apps as benign, suspicious, or malicious.
  • Built REST endpoints for app scanning, permission catalog lookup, alerts, and aggregate stats.
  • Structured a normalized MySQL schema for apps, permissions, app-permission mappings, and alerts.
  • Added contextual alerts with a short explanation and recommended action for every flagged app.
  • Built risk-distribution and top-permission charts, a searchable fleet table, and a live threat ticker.
How it works
1User scans an app by entering its name, package, and declared permissions.
2Backend sums weighted permission risk and normalizes it to a 0–100 score.
3Flagged apps trigger a contextual alert and appear on the dashboard's charts and live ticker.
