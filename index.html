AI + Expert System Preview

🧬 AI-Based Disease Prediction System

2026 · Machine Learning + Expert System

Developed a hybrid clinical decision-support prototype for breast-lesion classification using the Wisconsin Diagnostic Breast Cancer dataset. It combines a scaled Logistic Regression model with a rule-based expert system using MYCIN-style certainty factors, then fuses both outputs into a verdict, confidence level, explanation trace, warnings, and suggested next step.

Project TypeAI/ML web application
Core FocusBenign vs malignant classification
Key FeatureML + explainable rule-based fusion
Technical FocusPython + scikit-learn + Flask
Key features

The system provides a Flask web UI and JSON API, model training/evaluation, batch prediction, input validation, out-of-range warnings, and an explanation trace showing the expert-system rules that fired.

  • Uses 30 WDBC nucleus measurements covering radius, texture, perimeter, area, smoothness, compactness, concavity, concave points, symmetry, and fractal dimension.
  • Compares five classifiers with 5-fold cross-validation and deploys the scaled Logistic Regression model.
  • Runs a forward-chaining expert system with 9 finding rules and 11 diagnostic rules using certainty factors.
  • Fuses the ML probability and expert-system decision; disagreement produces an indeterminate result for confirmatory testing.
  • Includes Flask endpoints for prediction, feature metadata, sample cases, and health checks, plus unit/API tests and evaluation reports.
How it works
1User supplies the 30 breast-cell measurement features through the web UI or prediction API.
2The ML model estimates malignancy probability while the expert system derives findings and certainty-factor evidence.
3The fusion layer returns the verdict, confidence, explanation, warnings, and an appropriate confirmatory-testing next step.
